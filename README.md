# 📝 Dashboard

An intelligent and modular React Dashboard designed for flexibility and ease of use. It empowers users to personalize their workspace with draggable and configurable widgets, perform instant searches, and access a mobile-friendly interface. The system ensures persistent layouts using local storage, making it ideal for real-world use cases like analytics, monitoring, or personal productivity tools.

---

## 🚀 Features

- **Flexible Widget Control:**: Effortlessly add, remove, or adjust widgets to personalize your dashboard.
- **Instant Search & Filtering**: Locate widgets or data panels in seconds with the built-in search bar.
- **Live Data Updates**: Widgets automatically refresh to reflect the most recent information.
- **Organized Categories**: Arrange widgets into categories and switch between them with ease.
- **Persistent Layouts**: Your configuration is saved in local storage, ensuring it remains intact after reloads.
---

## 📦 Tech Stack

- **Frontend**: React, Tailwind CSS
- **State Management**: React hooks with localStorage
- **Deployment**: Vercel
